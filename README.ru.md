# Сергей Хвостов

AI-тренер. Интересуюсь искусственным интеллектом, анализом данных и автоматизацией исследований. Создаю инструменты и эксперименты с языковыми моделями и распознаванием речи на Python, Kotlin и Rust. Также занимаюсь качеством данных и проверкой информации по источникам.

## Проекты

У каждого проекта есть английское описание и отдельная русская инструкция.
