# Hi, I'm Sergei Khvostov

AI trainer interested in artificial intelligence, data analysis and research automation.
I build practical tools and experiments with LLMs and speech recognition, using Python, Kotlin and Rust.
I also investigate data quality and ways to verify information against sources.

## Selected projects

- [gigaam-android-ime](https://github.com/Servideus/gigaam-android-ime): an experimental offline Russian dictation keyboard for Android, built with GigaAM v3, Kotlin, Rust, JNI and ONNX.
- [deep-research](https://github.com/Servideus/deep-research): my fork of a multi-model research plugin, with independent cross-checking and primary-source verification.
- [thesis-task-proof-loop](https://github.com/Servideus/thesis-task-proof-loop): an agent workflow for academic writing, with source tracking, evidence checks and iterative verification.
- [Handy-GigaAM](https://github.com/Servideus/Handy-GigaAM): an experimental Handy derivative with GigaAM integration and Windows/Vulkan build fixes.

Most of these projects started with a problem I encountered in my own work.
